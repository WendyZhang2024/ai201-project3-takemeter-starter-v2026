# My three labels, copied verbatim from README.md -> Label Taxonomy.
# baseline.py reads this file as the entire prompt for the baseline model.
# No decision rule here: the baseline gets only the definitions the README
# gives, so any gap between baseline and trained model is measured on the
# same text a careful reader starts from.

question: a post whose main work is to get an answer from other people; it lays out a problem or a choice but does not conclude anything itself.
experience: a post whose main work is to report what happened to the author and what they concluded from it; it does not hand the reader something they can act on directly.
resource: a post whose main work is to hand the reader something they can act on directly — a file, a link, a setting, a checklist, or an explicit procedure; it does not mainly narrate the author's own experience.
